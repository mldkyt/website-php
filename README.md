# mldchan's website

mldchan's latest website, written in PHP. Looks exactly the same as [website-2026-02-28](https://git.mldchan.dev/luna/website-2026-02-28) but it's written in PHP.

## features

- functional guestbook
- anonymous messages with Sharkey support
- [uwurandom.php](https://github.com/breadtf/uwurandom.php)
- probably more but I'm too lazy to list it
- [a cool background](docs/Background.md)
- [cursor effects](docs/CursorEffects.md)

(the links above have tutorials for installation!)
