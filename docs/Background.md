
# The Background Stars Effect

## How do I add this effect?

1. To begin adding the background stars effect to your website, you need to add a script to your page. [Right click this link](https://mldchan.dev/scripts/background.js) and save it in your project to start.
2. You'll need to modify your code to be according to mine for it to work. Here's an example of how a page should look like
    ```html
    <body> 
        <canvas id="background"></canvas> 
        <div id="abovebackground" style="position: absolute; top: 0; left: 0; width: 100%; height: 100%; z-index: 1;"> 
            <!-- Your page content goes here! --> 
        </div> 
        <script is:inline defer src="/scripts/background.js"></script> 
    </body>
    ```
3. Make sure the script tag at the bottom of the page is pointing to the correct location of the script. If you have it in a different folder, make sure to change the path
4. Add my button to your website and make sure to give proper credit to my work!
