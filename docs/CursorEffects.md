# Cursor Effects

To add cursor effects to your website, [follow this link](https://github.com/tholman/cursor-effects?tab=readme-ov-file#how-to-use)

1. Append the script tag that's visible as the first thing in the head tag of your website. *Optionally open it and save it in your project and hist it on your own.*
2. Create a script tag under this script tag to add your cursor effects. Look below for examples.

    Here's my configuration, which you can copy and paste and it will give you a trans flag cursor:

    ```js
    cursoreffects.fairyDustCursor({
        colors: ["#5BCEFA", "#F5A9B8", "#FFFFFF"]
    });
    cursoreffects.rainbowCursor({ <br />
        colors: ["lightblue", "pink", "white", "pink", "lightblue"], length: 50, size: 5
    });
    ```
3. Customize and create your own configuration by following the documentation
